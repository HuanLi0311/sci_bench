Distances and world coordinates are in millimetres, +Y follows light. Signed s is objectY-lensY, v is imageY-lensY. We use v=f*s/(s+f) and transverse m=v/s. The intermediate object for the eye is the actual objective image location. A final virtual image uses backward ray extensions and a calibrated observer view; it is not projected onto a physical screen. A 0.05 mm object defines signed image height. Infinity and degenerate zero distances are explicit tagged nulls. The scene remains finite at near-focus limits.

Launch with `python3 -m http.server 8081 --directory /app/out` and open http://localhost:8081/microscope/. No network or build step is needed. The project vendors Three.js 0.169.0 and OrbitControls under MIT and uses system fonts. Save writes local storage and downloads JSON; Reload restores local storage; file upload loads an independent JSON file. Replay accepts state through window.microscope.applyState; the verifier starts a clean context. The specimen marker is illustrative; the exact object plane is the stage landmark.
