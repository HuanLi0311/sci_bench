# Sources and rights

All microscope geometry, drawings, samples, optical diagrams and target images are procedurally authored for this task and dedicated under CC0-1.0. They depict an ideal thin-lens assembly, not a third-party microscope. Generation code is in authoring/generate_materials.py and authoring/render_references.mjs.

Three.js and OrbitControls: https://github.com/mrdoob/three.js/tree/r169 ; npm three@0.169.0 ; MIT, copied notice in vendor/THREE-LICENSE.txt. Playwright 1.56.1 (Apache-2.0) is build-time/runtime tooling, never agent-visible answers. Browser binaries come from the immutable official image specified in both Dockerfiles. System fonts are used; no font files, remote images or external models are required.
