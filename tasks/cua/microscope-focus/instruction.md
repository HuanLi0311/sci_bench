# 显微镜装配与对焦 / Web3D

在 `/app/materials` 中有三视图、光学图、两个样本、三张目标图及离线 Three.js/OrbitControls 脚手架。请制作可编辑、可交互的显微镜 Web 应用。允许使用浏览器、终端和代码；这是 Web3D 开发任务，产物分数不代表纯 GUI 操作成功。

按参考图建 `body`、`stage`、`tube`、`objective`、`eyepiece` 五个独立非空网格，保留 `microscope` 父层级。地标误差 ≤2 mm，角度误差 ≤1°。使用空气中有限共轭薄透镜，物镜焦距 4 mm、目镜焦距 25 mm、名义镜距 160 mm。对焦必须改变真实载物台/镜片世界坐标，误差 ≤0.1 mm。按笛卡尔符号约定连续计算物镜、中间像、目镜的物距/像距、像高、横向放大率和朝向；像距误差 ≤1%，放大率 ≤2%。画出来自实际样本、经过实际镜片的两条主光线，实像使用会聚光线，虚像使用反向延长线，交点误差 ≤1 mm。

依照计算结果映射两个样本，而不是贴目标图。三组指定状态任一失败即整体失败；独立映射图 SSIM ≥0.90（唯一 normal 项，须通过），质心、尺度、朝向随变换闭合。处理近焦、无穷远和无有限成像情况，以 `null` 及明确的状态标记代替 NaN/Inf。实现对焦、样本切换、保存、重载、重置，保证重新加载恢复坐标及光学量。物镜位移 1 mm、其他合法组合扰动和未知棋盘样本会用于反作弊检查。

交付 `/app/out/microscope/`（全部源码、本地依赖、样本），以及 `/app/out/{state.json,replay.json,report.md,manifest.json}`。状态须含资料指定的三组设置；报告说明单位、符号、实像/虚像及启动方法；manifest 覆盖参考图、样本、依赖与所有新增素材。仅使用系统字体或随包附许可的本地字体。不得引用 CDN、外网字体或远程模型，断网必须可运行。可用 `python3 -m http.server 8081 --directory /app/out` 启动，打开 `/microscope/`。
